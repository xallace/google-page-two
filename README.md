# Google, Page Two

A searchable guide to 26 underrated Google sites, apps and search tricks, from searching inside scanned PDFs to scrubbing through forty years of satellite photos.

**Live:** https://xallace.github.io/google-page-two/

## What's in it

| Category | Tools |
| --- | --- |
| Research & reference | Google Patents, Scholar alerts, Dataset Search, Books Ngram Viewer, Fact Check Explorer, Arts & Culture |
| Maps & Earth | Google Earth Pro, Earth Timelapse, Google Flights Explore |
| Workspace power features | Drive OCR, Apps Script, Sheets web functions, Gmail plus-addressing, Takeout, Inactive Account Manager |
| Small tools | Chrome Remote Desktop, Quick Share for Windows, Squoosh, Teachable Machine, AI Studio |
| Mobile | Live Transcribe, Translate conversation mode, Snapseed |
| Search tricks | The Web filter (`&udm=14`), date and file-type operators, Verbatim mode |

## Features

- Live search across names, descriptions and categories, with highlighted matches. Press `/` to focus, `Esc` to clear.
- Category filters with match counts.
- Copy buttons for snippets such as `&udm=14` and `IMPORTHTML`.
- Light and dark mode, following the system setting.

## Tech

One static `index.html`, no build step and no dependencies. Plain HTML, CSS and JavaScript, with fonts from Google Fonts (Archivo, Newsreader, IBM Plex Mono). Served by GitHub Pages from `main`.
